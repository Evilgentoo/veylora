# GN-Math local mirror in Veylora

This directory was generated by `07-gn-math-selfhost-import.py`.

Upstream repositories:
- https://github.com/gn-math/html — single-file game pages
- https://github.com/gn-math/assets — supporting assets and `zones.json` catalog
- https://github.com/gn-math/covers — game cover images

Veylora maps game pages and cover art to local files under this directory; the Games UI does not need to fetch the GN-Math site at runtime. Some individual games may still rely on third-party network APIs or CDNs not included in these repositories.

The upstream catalog names game creators/publishers, and the repositories do not appear to provide a blanket license for every third-party title. Review applicable rights/licenses before publishing this mirror.
